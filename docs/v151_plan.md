# V15.1 ROS2 개발·검증 계획

## 목표와 범위

사용자 요청(2026-10-01): V15 토크 최적화, V16 기립 통합, 앉았다 일어서기,
필요시 추가 학습, 이후 개발은 ROS2 제어 + Isaac Sim 검증, 다리 충돌 확인.
넘어진 자세 복구는 범위에 포함하지 않는다. 초기 앉기는 네 발로 지지하는 낮은 자세다.

## 구조

- ROS2 `v151_ros2_control`: 기존 235차원 V15 정책, 자세/보행 전환, V16에서 가져온
  모델 기반 기립, 필터와 모터 토크 가드. 제어 노드에서 Isaac 모듈을 import하지 않는다.
- 기립 동역학은 검증된 MJCF/Pinocchio 모델로 계산한다. PhysX M/h/J를 노드에 전달하지 않는다.
- Isaac Sim 브리지는 상태·깊이·접촉을 발행하고 관절 목표를 적용한다. 기본 관절 드라이브는
  V15의 Kp=300, Kd=8, 한도 24.8/48 Nm를 유지한다. 기립 토크는 측정 q,dq에서 동등 PD
  위치 목표로 변환한다. 이 변환과 implicit PD의 차이는 실험에서 확인한다.
- ROS2 전달 순서: 상태/영상 → 정책·상태기계 → 관절 목표 → PhysX. +y가 로봇 전방이다.
- 초기 검증은 시뮬레이션 시간 lockstep이다. 실기 타이밍·모터 식별 완료로 주장하지 않는다.

## 독립 작업

1. 정격 8.3/18/18 Nm 기반 부하 비용으로 소규모 재학습 후보 생성. 기존 V15 체크포인트 보존.
2. 외부 로봇 모델을 사용하는 기립/상승 제어 코어와 단위 검증.
3. ROS2 패키지/상태기계/Isaac 브리지와 충돌 계측 통합.
4. ws1, Slurm QoS admin, 1 GPU 작업을 순차 실행해 통합 동작과 보행 후보 비교.

## 합격 기준 및 기록

- 초기화 후 상태 재설정 없이 앉음→상승→기립→보행→정지→기립을 수행한다.
- 전환 실패·넘어짐·타임아웃을 성공으로 대체하지 않는다. 상태 전환, 높이, 기울기,
  실제 이동, 접촉, 명령 지연을 기록한다.
- 평지/거친 지형 동일 seed·명령·시간에서 V15 대비 생존 악화 없음, 진행거리 ≥90%,
  명령 추종 오차 증가 ≤0.02 m/s. 토크 RMS/기계적 절대 파워 악화 없는 후보를 우선 채택한다.
  개선하지 못한 후보는 최적화 성공으로 명명하지 않는다.
- 정격 초과 시간, 관절별 RMS·최대 토크, 전류 환산, 다리 간 최소 간격/접촉을 보고한다.
  전류는 τ/(Kt·감속비), 열 안전성과 배터리 전류는 별도 미검증이다.
- 충돌 필터·충돌 형상과 활성 접촉 쌍을 기록한다. 비활성 쌍은 무충돌 증거가 아니다.
- 자기충돌 채택 기준(2026-10-01, ROS2 비교 물리 결과 확인 전 고정): 후보의 다리 간 최대 접촉력 ≤1 N이고 캡슐 최소 간격 ≥−0.002 m여야 한다. 몸통 프록시 겹침은 별도 보고하며 채택 게이트에 포함하지 않는다.
- V16 계단은 사용자 지시로 제외한다. V15.1 계단 검증은 별도 결과로 기록한다.

## 검토할 경계 조건

관절 순서 변환, body/world 프레임, stale ROS 메시지, 전환 시 필터 초기화,
접촉 없는 상승/기립, 관절 포화, 다리/몸통 충돌 필터, 최초 실패 이후 데이터 제외.

자동 commit/push 없음. 모든 GPU 물리는 ws1 Slurm에서 실행한다.

## 591번 물리 시험 이후 구동 경로 수정

첫 위치 환산형 기립은 목표 .464 m 대비 .419 m에서 안정화돼 높이 게이트를 통과하지 못했다.
위치 차분 속도와 PhysX 보고 속도의 불일치도 확인됐다. 원인을 구분하기 위해, V16과 같이
기립을 직접 effort로 구동하고 V15 보행은 기존 implicit PD로 유지하는 혼합 명령(스키마2)으로
수정한다. 높이 합격 기준은 완화하지 않는다. 비교592는 동결된 보행 경로로 계속 비교하며,
스키마2의 w=1 위치 목표/게인/명령 effort가 그 경로와 일치하는 회귀 테스트를 유지한다.

### 추가 토크 최적화: 2026-10-01, 기준 601

- 사용자의 추가 최적화 지시에 따라 낮은 자세 및 정지 후 기립 정격 초과를 우선 줄인다.
  앉는 깊이 0.10 m, 보행 명령 0.4 m/s, 원본 정책 339, 기존 물리/모터 한도는 유지한다.
- CPU로 nominal 및 601 최종 지지 발 배치의 자세/정적 부하를 탐색한다. WBC 비용 증가는
  원하는 가속도 추종을 희생해 토크가 낮아 보일 수 있으므로, 첫 물리 후보는 기존 QP 비용을 쓴다.
- 기립과 낮은 자세의 전방 이동량을 독립 설정하고 초기 1초에는 5차 보간한다.
  이동 중 관절 목표는 발 anchor를 유지하는 IK를 사용한다. 보행 후 착지/접촉 규칙은 유지한다.
- 물리 후보 616: 기립 +0.09 m, 낮은 자세 +0.15 m, 601과 같은 seed42/평지/28초 전체 시퀀스.
  ROS2 DDS 포함 61 테스트 통과 후 compute/admin Slurm으로 제출했다.
- 후보 결과 확인 전 채택 기준: 전체 시퀀스/충돌 검사 통과, 리셋 없음/유한값,
  최종 높이 기준 대비 ±1 cm, 전진 거리 기준의 90% 이상, 26.5–28초 최종 SIT 유지.
  그 낮은 자세 구간의 최대 정격 대비 관절 RMS가 10% 이상 감소하고, 초기/정지 후 STAND의
  최대 정격 대비 RMS가 증가하지 않아야 한다. WALK 평균 관절 RMS 증가 없음 및 속도 MAE
  기준+0.02 m/s 이하, 전체 정격 정규화 RMS 감소, 실제 설정 모터 구동 상한 준수를 요구한다.
  실패 후보는 새 기본값으로 채택하지 않으며 원본 601 증거를 보존한다.
- 616은 물리 표본 0개, 첫 ROS2 명령(0초) 수신 timeout으로 종료했다. 자세 안정성/토크 실패로
  해석하지 않는다. 발 접촉 subscriber와 status publisher의 연결을 시작 게이트에서 빠뜨린
