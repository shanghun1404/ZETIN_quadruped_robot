# V14 다리 간 충돌 방지 설계

## 목표와 기준

V13에서 선택한 V11 보행 액터, V12 depth→scan 학생, 25 Hz 목표 필터와 0.99
모터 토크 가드를 유지한다. 서로 다른 다리의 허벅지·종아리가 관통하며 꼬일 수 없도록
PhysX 자기 충돌을 모델에 추가한다. 학습과 모든 시뮬레이션은 HPC `ws1`에서 한다.
원본 `v2_plain.usd`는 수정하지 않는다. 입력 SHA-256은
`3df1d83c036f4679ab183440a3de9520537f037a461f7e1e0a10e43ec0df6e18`로
고정한다.

## 방법

파생 USD가 원본 `/quadruped`를 참조한다. 검증된 visual proxy fitting 결과의
`FL/FR/RL/RR_{thigh,calf}_profile` 로컬 중심 `(0.125, 0.09, 0.24) m`, X축
원통 길이 `0.23 m`를 사용해 링크당 캡슐 하나를 추가한다. 원본 프로파일 반지름
`0.01 m`보다 큰 `0.02 m`를 V14 충돌 외피로 사용한다. 원본 발 4개 충돌 형상은
그대로 보존한다. 다른 장식용 링크에는 충돌 형상을 추가하지 않는다.

PhysX 자기 충돌을 켜고 `UsdPhysics.FilteredPairsAPI`로 **같은 다리**의
허벅지·종아리·발 세 링크 사이만 필터링한다. 서로 다른 다리의 8개 캡슐과 발은
서로 충돌한다. 장면 생성 후 물리 시작 전에는 [`v14_terrain_filter.py`](../config/v14_terrain_filter.py)가
`/World/ground`에 필터 쌍을 작성해 새 캡슐만 지형에 닿지 않게 한다. 원본 발
충돌은 지형과 계속 작동한다. 이는 원본을 참조하는 USD 내부에서 참조 범위 밖의
`/World/ground`를 대상으로 지정하면 OpenUSD가 그 관계를 무시하기 때문에
장면 USD 계층에 작성한다. IsaacLab의 `prestartup` 이벤트와
`replicate_physics=False`를 사용한다.
[OpenUSD 충돌 그룹/쌍 필터](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/rigid_bodies_articulations/collision.html)와
[Isaac Sim 자기 충돌 가이드](https://docs.isaacsim.omniverse.nvidia.com/latest/openusd_tuning_tutorials/tutorial_03_collider_pairs.html)를
기준으로 구성한다.

첫 검증에서 반지름 0.02 m 후보는 다리 관통을 막았지만 기존 V11 액터의
평지 전진 거리가 8.00 m에서 3.20 m로 줄었다. 반지름을 0.015 m로 줄여도
1.29 m로 회복되지 않았다. 다리 충돌을 모두 끈 충돌 그룹 후보는 7.99 m를
회복했지만 최대 관통이 다시 30 mm여서 기각했다. 이 결과에 따라 V14는
반지름 0.02 m를 유지하고 정책을 추가 적응시킨다. 학습은 V11 보상표에
V13의 25 Hz 필터와 0.99 토크 가드를 적용하고, V12 학생은 고정한다.

## 검증 순서와 채택 기준

1. 파생 USD 정적 검사: 원본 해시, 8개 캡슐, 기존 발 4개, 같은 다리 필터
   12쌍, 자기 충돌 설정을 확인한다. 기존 관절·질량 속성은 작성하지 않는다.
2. HPC 중립 서기: 자기 충돌을 켠 채 2초간 정상 지지하고, 충돌로 몸체가 튀거나
   넘어지는지 확인한다. 원본 USD와 동일한 초기 자세를 사용한다.
3. HPC 교차 자세: 원본과 파생 USD에 동일한 관절 목표를 주어 서로 다른 다리의
   충돌 외피 관통을 비교한다. 필터가 필요한 같은 다리 접촉과 실제 다리 간
   접촉을 구분해 기록한다.
4. HPC 적응 학습: V11 액터를 시작점으로 충돌 모델에서 PPO를 학습한다.
   가드를 활성화해 모터 한계 초과 요청 없이 새 자세를 익히게 한다.
5. HPC 보행: V13 검증과 같은 시드 42·43·44, 평지·험지 L4·계단 L5의
   32개 환경, 12초 평가를 반복한다. 생존·계단 통과가 기준에서 크게 떨어지지
   않고, 모터 초과 요청 0%가 유지되어야 채택한다. 진행 거리와 파워 손실도
   기록한다.

정적 검사는 물리적 접촉을 증명하지 않는다. 교차 자세에서 접촉 방지 효과가
확인되지 않으면 충돌 형상이나 필터를 수정한다. 학습 뒤에도 평지·지형
진행과 계단 통과가 기준에 크게 못 미치면 V14를 채택하지 않는다.
