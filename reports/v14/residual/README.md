# V14 보정 정책 — 파일럿 결과

후속 실행: [128환경·3,000회 추가 훈련](../residual_scale/README.md) 진행 중(작업186).
아래는 기존32환경300회 파일럿의 완료 결과다.

**보정 policy 구현,300회 훈련 및 추가 시드 검증을 완료했다.**
`model_100.pt`는 생존 개선을 보인 후속 실험 후보로 보관한다.
방향·경로 조건 미달과 지표 간 상충이 남아 최종 V14로 채택하지 않는다.

사용자 승인: 기존 보행 정책을 고정하고 작은 보정 policy만 훈련한다.
[설계](../../../docs/v14_residual_design.md) · [계획](../../../docs/v14_residual_plan.md).

## 구현

- V14 5700 actor 및 V12 시각 모델 동결. 추가 actor/critic은128×128 ELU.
- 입력307차원: 기존 관측235, 기준 action12, 다리 간격24, 접근속도24,
  직전 보정12. 실제 합성 action이 기존 정책의 다음 관측에 반영된다.
- 12관절 보정은 `.05*tanh(raw)` rad. 탐색 잡음도 이 한도 안에 있다.
  합성 action 이후 기존25 Hz LPF·0.99 토크 가드를 적용한다.
- 기존 보행 보상에 다리 접근, 보정 크기, 보정 변화 비용을 추가한다.
  reward manager에서 종료·리셋 전 상태를 계산한다.
- 기존 비교군과 같은 조향 제어를 사용하며 yaw 보상은 원래 값(std2,weight5)을
  유지한다. 이전의 강한 yaw 보상 적응은 사용하지 않는다.
- 저장된 모든 보정 checkpoint의 SHA-256과 기준 actor/student/USD 해시를
  manifest에 연결한다. 평가에서 파일 또는 .05 rad 상한이 다르면 거부한다.

## 두 시드 합계와 결정

시드42는 중간/최종 후보 선택에 사용했고, 시드43에서 중간100을 추가 확인했다.
각 시드32개 환경, 같은 고정 계단과 조향 제어다. 간격 비율은 살아 있는 환경
프레임 수로 가중했다. 두 시드만의 파일럿이며 광범위한 지형 검증은 아니다.

| 지표 | 기존5700+조향 | +보정 model100 |
|---|---:|---:|
| 계단 생존 | 49/64 | 55/64 |
| 방향·경로 통과 / 전체 계단 | 0/64 / 0/64 | 0/64 / 0/64 |
| 평균 전진 | 2.098m | 2.054m |
| 평균 최대 횡이탈 | 2.279m | 2.341m |
| 평균 최대 방향 오차 | 66.15° | 68.41° |
| 모든 외피 겹침 프레임 | 0.6629% | 0.7234% |
| 간격 -2mm 미만 프레임 | 0.2469% | 0.2082% |
| 최저 외피 간격 | -16.16mm | -14.77mm |

[두 시드 집계](comparison_2seeds.json). 생존 증가와 깊은 겹침 감소는 확인했지만,
전체 겹침·횡이탈은 증가했다. 실제 진행도 약2.1% 감소했다. 따라서 충돌 회피와
보행 성능이 모두 개선됐다고 주장하지 않는다. 평지는32/32 생존과 겹침0%를
유지했고, 모든 이번 보정 평가에서 가드 적용 후 토크 초과 요청은0%였다.

**결정:** 중간100을 후속 실험 후보로 보관하고 기존 기준 모델은 교체하지 않는다.
다음 개선은 이 고정 기반 구조에서 횡이탈·방향 오차를 정책이 구분해 관측하도록
하고, 경로 유지 목표를 함께 학습시키는 방향이 적절하다. 이 확장은 아직 구현·검증하지
않았다. 단순히300회 이후 훈련을 계속하면 좋아진다는 근거는 없다.

정지·험지·내리막과 실제 로봇은 이번 후보의 검증 범위 밖이다. 간격은 기존20mm
충돌 외피의 다리24쌍을50Hz로 측정하며 발과 다리의 모든 조합을 포함하지 않는다.
음수 외피 간격을 그대로 실제 시각 메시 관통 깊이라고 해석하지 않는다.

## 검증 범위와 실행 판단

- 0 보정의 실제 궤적과 토크 결과가 기준과 정확히 일치한 뒤 훈련했다.
- 사용자 지시에 따라 훈련과 physics 실행은 모두 HPC에서 수행했다.
  순수 검사와 HPC 통합으로 검증했고, 다른 과거 실행 경로 전체를 검사하지는 않았다.
- 시드42에서 지표가 엇갈렸지만, 생존과 깊은 겹침 변화가 다른 시드에서도
  나타나는지 판단하려고 평지/추가 시드 평가2건을 수행했다. 결과는 위 표와 같다.
- 새 스킬 승인 절차를 추가하지 않고 사용자가 승인한 설계와 '진행해'에 따라
  구현했다. 자동 commit하지 않았고 기존 worktree 및 실험 기록을 보존했다.
- 코드 검토의 Important3건은 모두 수정했고 보류한 Minor는 없다.
- [코드 해시](code_sha256.json), [Slurm 종료 상태](hpc_jobs.txt),
  [원본 USD 확인](provenance.json)에 재현 근거를 보관했다.

일부 지표가 개선된 파일럿이며, 아직 V14 완료 모델로 채택하지 않았다.
실제 로봇 적용을 위한 관절 기반
FK 간격 계산은 구현하지 않았으며, 현재는 시뮬레이터 강체 자세에서 기하학적
간격을 계산한다. 모델 입력은 지형의 비공개 정답이나 접촉 충격량을 사용하지 않는다.
