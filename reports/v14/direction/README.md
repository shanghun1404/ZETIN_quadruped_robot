# V14 방향 복구 파일럿 (2026-09-26)

후속으로 기존 actor를 고정한 [보정 policy 파일럿](../residual/README.md)을 진행했다.
아래는 그 이전 방향 보상 적응 실험 기록이다.

**이번 방향 복구 파일럿과 비교 평가는 완료했다. 새 모델은 채택하지 않는다.**
고정 지형·정확한 경로 판정과 조향 제어 옵션을 구현했지만, V14의 계단 보행과
다리 꼬임 방지 문제는 해결되지 않았다. [설계](../../../docs/v14_direction_design.md),
[계획](../../../docs/v14_direction_plan.md).

## 확인한 문제와 수정

기존 평가의 L5는 행 번호였고 실제 단높이는 무작위였다. `fixed_v2`는
단높이를 정확히 0.157142857 m로 고정하며 32개 로봇을 32개 타일에 분리한다.
SDK 실제 지형 원점 32개 모두 -1.100000024 m로, 전체 상승 높이 1.1 m와
일치함을 작업 157에서 확인했다. 유효한 타일 내부 궤적의 지면 측정은
실제 계단 식으로 계산한 높이와 최대 5.1e-6 m 차이였다.

보강된 통과는 생존, 최종 전진>=2.1 m, 최종 지면 상승>=2단-2cm,
최대 횡이탈<=0.6 m, 최대 방향 오차<=60도를 모두 요구한다.
전체 계단 통과는 별도로 전진>=3.6 m와 전체 높이 1.1 m 도달을 요구한다.
몸체만 튀어 오른 경우나 옆 계단으로 돌아서 벗어난 경우를 통과로 세지 않는다.

초기 방향·경로를 복구하는 yaw 명령을 기존 235차원 관측에 전달한다.
복구 제어는 episode 시작점/방향을 보존하고 정지 명령에서 회전하지 않는다.
첫 훈련의 yaw 추종 보상은 std=0.25 rad/s, 가중치=7.5였다.
이 훈련은 계단 균형을 악화시켜 채택하지 않는다. 추가 후보는
std=0.5, 가중치=5.0, 학습률=1e-4로 적응 강도를 낮췄다.

## 결정과 다음 개선 방향

- 강한 적응의 중간·최종 모델과 약한 적응 모델을 모두 제외한다.
  기존5700이나 V13 기준 모델을 이 모델들로 교체하지 않는다.
- 조향 보정은 선택형 실험 기능으로 남긴다. 두 시드에서 방향은 회복됐지만,
  생존은48/64→49/64이고 횡이탈·다리 외피 겹침이 증가했다.
- yaw 보상을 강화하는 동일한 학습을 더 연장할 근거는 없다.
  다음에는 충돌 직전의 **어느 다리 쌍이 접근하는지, 관절 각도·속도가
  어떻게 변하는지**를 기록해 보행 실패와 연결하는 것이 우선이다.
  해당 진단 후 기존 보행을 보존하면서 간격을 확보하는 보상을 검토한다.
  이 후속 방법의 효과는 아직 검증하지 않았다.
- 모든 훈련·시뮬레이션은 HPC에서 실행했다. 이번에는400회 훈련과9개
  비교 평가를 완료했고, 최종 확인 시 작업157~168 중 의도적으로 취소한158
  외에는 모두 `COMPLETED 0:0`이었다. 진행 중인 작업은 없다.

### 실행 중 판단한 사항과 한계

- Isaac을 가져오는 전체 저장소 검사는 로컬에서 실행하지 않고 관련 순수
  검사와 HPC 통합 실행으로 검증했다. 다른 과거 실행 경로까지 검증한 것은 아니다.
- 첫 훈련에 관측 차원·고유 타일 스모크를 합쳐 중복 simulator 시작을 줄였다.
  뒤늦은 오류가 있었으면 훈련 작업 일부가 낭비될 수 있는 선택이었다.
- 지면 스캐너의20 m offset에 대한 검토 우려는 SDK 초기화 경로와 실제
  계단 높이 비교로 해소했다. 현재 검증 범위 밖의 센서 설정에는 일반화하지 않는다.
- 강한 적응이 실패한 뒤 약한100회 후보를 추가했다. 이 후보도 실제 계단에서
  실패했으므로 훈련 보상 증가를 성능 개선으로 해석하지 않았다.
- 약한 후보는 첫 계단 평가에서 탈락했으므로 평지·추가 시드 평가는 진행하지
  않았다. 모든 모델의 모든 지형 성능을 확인한 실험은 아니다.

첫 훈련의 학습률은 고정3e-4이며 두 훈련 모두 기존5700에서 optimizer를
초기화하고 시작한다. 낮은 학습률 후보는 고정1e-4로100회만 훈련했다.
기존 USD, 0.99 토크 가드, 25 Hz LPF, V12 학생은 유지했다.

## 코드 검증

로컬 관련 검사25개 통과, HPC CPU 방향 tensor 검사3개 통과.
별도 검토에서 발견한 두 Important 항목(설정 분기 오류,
지형 치수가 없는 legacy 궤적의 잘못된 통과 판정)은 실패 재현 검사 후 수정했다.
legacy 궤적 출력은 simulator 시작 전에 거부하며 계단 성공 계산은 양수 치수를 요구한다.

보류한 Minor: 평가 launcher의 scenario/seed 기본값과 `shift 4`가 일치하지
않는다. 이번 작업은 모두4개의 위치 인자를 명시했으므로 실행에 영향이 없다.

재실행 시 `actor label scenario seed` 네 위치 인자를 모두 지정한다.

```bash
sbatch launch_v14_direction_eval.sbatch /absolute/path/model.pt new_label stairs_up 42 --heading-control
```
