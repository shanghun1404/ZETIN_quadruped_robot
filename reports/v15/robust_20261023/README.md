# V15 외란·모터 지연·센서 노이즈 강건화 추가 훈련 (2026-10-23)

## 결론

Jetson 번들의 `model_15699.pt`(SHA `9a440065…`)에서 이어서 11,200 iteration을 추가로 학습했다.
학습 중에는 밀기, 모터 지연·명령 누락, 센서 노이즈를 점진적으로 키웠다.

최종 `model_26899.pt`(SHA `18f0597d…`)의 결과는 다음과 같다.

- **좋아진 점**: 센서 노이즈와 지연이 있을 때 요 각속도 추종 오차가 기존 모델의 약 절반이 됐다.
  - 노이즈 2배: 0.214 → 0.088 rad/s
  - 지연 40 ms: 0.112 → 0.053 rad/s
- **나빠진 점**:
  - 1.0 m/s 밀기에서 넘어짐: 9 → 23회
  - 정상 조건 속도 추종 오차: 0.026 → 0.042 m/s
  - 기존 ROS2/Isaac 9개 시험: **9/9 → 7/9**. `rough`는 옆으로 1.56 m 밀려 통로를 벗어났고, `yaw`는 회전이 0.64 rad 초과했다.

**실기 교체 후보로 채택하지 않는다.** Jetson 모델은 `model_15699`를 그대로 유지한다.
모든 결과는 Isaac 시뮬레이션 결과이며, 실제 로봇 검증 결과가 아니다.

`--robust`를 줄 때만 켜진다. 옵션이 없으면 기존 학습과 동일하다. 구현은 [`config/v15_cad_robust.py`](../../../config/v15_cad_robust.py)에 있다.

## 해석 (추정, 검증 안 함)

- **밀기에 약해진 이유 후보**
  - 몸통 선속도 노이즈(±0.15 m/s) 때문에 정책이 속도 관측을 덜 믿게 되어, 밀림에 대한 반응이 둔해졌을 수 있다.
  - 학습 중 밀기 크기가 U(0, 1.0)이라 강한 밀기의 비중이 작았다.
  - 표본 수가 계획의 절반이었다.
- **정상 조건 회전 초과·옆 이동**: 노이즈 아래에서 요·횡방향 응답 이득이 바뀐 것으로 보인다. retention 가중치를 1.0으로 낮춘 것도 기존 동작 유지력을 줄였을 수 있다.

어느 요인이 원인인지는 하나씩 떼어 보는 실험(밀기만 / 노이즈·지연만)을 해야 알 수 있다.

## 진행 중 문제와 처리

- **Isaac Sim 시작 실패**: viewport camera null prim 오류가 간헐적으로 났다. 이번 밤 12회 시작 중 4회(9573, 9583, 9590 첫 시도, 9592)이며, seed와는 관계없다.
  - 학습 런처는 preflight 전에 실패하면 1회 다시 시도한다.
  - 실패 로그는 [failed_starts/](failed_starts/)에 있다.
- **평가 스크립트 오류**: 첫 판에서 두 번째 시나리오의 `env.reset()`이 inference tensor 오류를 냈다(job 9580). reset을 inference mode 안에서 하도록 고친 뒤 job 9582로 확인했다.
