## 단위·좌표

- 미터, 킬로그램, Z-up. Fusion 의 mm 월드 좌표를 그대로 m 로 바꿨고 로봇 원점 = Fusion 원점(몸체 바닥면 중앙 부근).
- +y 가 앞(F), x>0 이 오른쪽(R). 영점 자세(모든 조인트 0°) = 네 다리가 수직으로 선 자세.
- 링크 Xform 은 모두 단위 행렬이고 부품은 월드 변환으로 배치했으므로, 조인트 위치와 질량중심은 모두 이 공통 프레임 값입니다.

|---|---|---|---|
| AK10-9 (엉덩이 피치·무릎) | 53 N·m (데이터시트 피크) | 60 N·m/rad | 3 N·m·s/rad |

- 연속 토크로 제한하려면 maxForce 를 AK10-9 18 N·m, AK70-10 8.3 N·m 로 낮추세요.

## 충돌·접촉

- 체결부품(볼트·너트·인서트·핀 488개)을 뺀 모든 부품 67개에 `PhysicsCollisionAPI` + **convexHull** 근사. 각 부품이 개별 볼록껍질이라 다리끼리, 다리와 몸체, 바닥과 모두 부딪히며 통과하지 않음.
- 볼록껍질이라 몸체 셸 내부 공간·knee 컵 안쪽은 메워진 것으로 취급됨(내부에 들어갈 물체가 없으므로 영향 없음). 더 정밀하게 하려면 해당 부품의 `physics:approximation` 을 `convexDecomposition` 으로 바꾸면 됨.
- 관절 구조의 **자기 충돌 켜짐**(`physxArticulation:enabledSelfCollisions = 1`). 조인트로 직접 연결된 두 링크 사이는 PhysX 기본대로 충돌 제외(모터·허브가 겹치는 부분).
- 물리 재질(정지/운동 마찰, 반발): PLA 0.5/0.4/0.05, 알루미늄 0.4/0.35/0.05, 모터(강) 0.4/0.3/0.05, 테니스볼(고무) 0.9/0.8/0.1, 바닥 0.8/0.7/0. **모두 일반적인 가정값**이며 실측값으로 바꾸길 권함.
