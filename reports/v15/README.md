## Jetson / STM32G474 USB 배포 준비 (2026-10-12)

사용자 확인에 따라 Jetson Orin Nano Super / Ubuntu24.04 / ROS2 Jazzy를 대상으로 준비했다.
최신 `model_15699.pt`, 동결 depth student, 원본 CAD 기립 WBC와 ROS2 USB gateway·센서 정렬을 포함한다.
12개 관절의 목표각·속도·Kp·Kd·feedforward와 실측 관절 피드백을 USB로 송수신한다.
기본 모터 비활성, host50ms/MCU100ms watchdog이며 재연결 시 자동 활성화하지 않는다.

로컬 범위별117시험, 압축 해제한 번들의 native Jazzy108시험이 통과했다.
C12/HAL stub4/emulator5/교차언어3(100벡터) 및 실제 actor/student/CAD 초기화를 확인했다.
Simulator import 없이 실행하며 실제 Jetson ARM 성능이나 CubeMX/G474/CAN 시험으로 해석하지 않는다.
실모터 CAN callbacks, ID·부호·영점 보정과 실제 깊이·오도메트리·접촉 센서 입력은 연결해야 한다.

새 USB codec Isaac 3개 시험(job2355, QoSadmin)은 **2/3 통과**했다. 평지14초와18cm 통합30초는 통과했고,
10cm 통합은 정지→기립 복귀 중19.04초에 실패, 비인접 자가 접촉375.58N을 기록했다.
기존2343과 시험 순서·월드 원점이 달라 전체 순서를 맞춘 비교2424를 실행했고 **4/4 통과**했다.
요철24초·기립12초·10/18cm 통합 각30초를 완주했고, 정격 RMS 초과0/48·피크 한도 초과0·자가 접촉0N이었다.
공통281소스와 checkpoint가 같고 실제 물리 상태·접촉·적용 토크 시계열도 기존2343과 동일했다.
실패2355의 다른 시험 순서·좌표에서 안정성이 해결됐다고 보지는 않는다. 같은 실패 조건을 USB 왕복 없이
기존 ROS2 경로로 재현한 대조2432에서도2/3이며, 10cm는19.04초·375.58N으로 동일하게 실패했다.
USB2355와 공통284소스·checkpoint·실제 물리/명령 시계열이 같아 이 비교의 실패는 codec 삽입으로 추가된 것이 아니다.
