TJA1051T/3: 세 채널 TX→RX 경로 확인

사용자가 E5V에 별도 5V 공급, VIO=3.3V를 확인한 뒤 재시험했다. 도면에 맞춘 v3 펌웨어는 CAN1=PA12/PA11, CAN2=PB13/PB12, CAN3=PA15/PA8을 사용한다. MCU의 GPIOA/B 입력 레지스터에서 실제 TX와 RX 패드를 표본화해 프레임을 독립 디코딩했다.

각 모드의 30초 측정 명령은 6,000개, 2초 예열은 400개다. 12관절의 가상 각도 응답을 모두 검증했고 피드백 소스 시퀀스 누락은 0개다. 호스트 일정 지연은 별도 열에 보존했다.

정상 CAN 모드에서도 12개 TX 및 RX 프레임의 CRC까지 정상임을 확인했다. 세 채널 모두 기존 Bit0 오류(LEC=5)가 사라지고 ACK 오류(LEC=3)만 남았다. 외부 CAN 노드가 연결되지 않은 현재 구성에서 ACK를 받지 못하는 결과와 일치한다. 정상 모드의 송신 완료는 각 버스 0/4개로 기록했으며 외부 전달 성공으로 계산하지 않았다.

확인 범위는 트랜시버를 거치는 자기 송수신 경로다. CAN_H/L 전압 파형은 오실로스코프로 측정하지 않았다. 모터 응답·실제 각도 추종은 아직 확인하지 않았다. 연속 시험의 각도 응답은 가상 AK이며 FDCAN external loopback을 쓴다. 시험 후 CAN 연속 명령 생성 프로세스를 종료하고 진단 기본 모드로 복귀했다.
