자연 보행에 실패했습니다. IsaacLab 자체 프로덕션 4족 설정(Spot)을 조사한 결과

## ⚠️ 이 체크포인트의 한계

`model_1900.pt`는 **진행 방향이 반대로 학습된 버전**입니다.
`guide_frame`은 안내견 정면을 base **−x**로 정의하는데, 이 실행은 스톡 규약대로
+x를 명령했습니다. 실측 발 위치(FL +0.211 / RL −0.223)로 확인했습니다.

수정 후 재학습이 진행 중이며, `config/`의 소스는 **수정된 최신본**입니다
(`V8_BASE_LIN_VEL_X_RANGE = (-0.9, -0.3)`). 보행 품질 지표는 방향과 무관하게
유효하지만, 배포용 체크포인트는 재학습본으로 교체해야 합니다.
