# quadruped — Isaac Sim 용 USD v5 (2026-10-24)

Fusion "quadruped robot_v5_structure_2026-10-24"(구조 재설계, 수정 내역 §19)에서 다시 만든 물리 모델. 파일 구성·좌표·조인트·구동기·충돌 설정은 v2(`../isaac_usd/README_isaac.md`)와 같고, **링크 구성 부품과 질량 속성만 바뀜**. `quadruped_scene.usda` 를 열 것(세 `.usda` 는 같은 폴더).

## v2 대비 바뀐 점

| 링크 | 바뀐 부품 | v2 질량 | v5 질량 |
|---|---|---|---|
| `*_hip` | combine_1 → 엉덩이 요크 본체 + 뒤 측판(BL 은 전용 부품) | 1.036 kg | 1.247 kg |
| `*_thigh` | 허브 통·덮개, 허벅지 클램프 ×2 | 0.636 kg | 0.817 kg |
| `*_shank` | 무릎 컵 + 뒤 캡(신규), 정강이 커버(5 mm 짧음) | 1.291 kg | 1.494 kg |
| `base` | 변화 없음 | 11.242 kg | 11.242 kg |
| 합계 | | 23.09 kg | **25.48 kg** |

- 출력물 질량은 PLA 솔리드 값. 실제 출력은 무릎 컵·캡·허브가 벽 6 + 인필 40 % 라 그만큼 가벼움(슬라이서 기준 무릎·허브 4세트 2.1 kg vs 솔리드 약 3.0 kg) → 시뮬레이션은 약 0.9 kg 무거운 쪽(보수적).
- 관절 위치·축(`joints_fixed.json`)·가동 범위·구동기 설정은 v2 그대로(관절 축 위치를 바꾸지 않았으므로).
- 모델 안 볼트 형상은 v2 것(질량 근사).

## MuJoCo 교차 확인 (`mujoco_check.py`, 결과 `mujoco_check_result.json`)

Isaac Sim 이 이 PC 에 없어 MuJoCo 3.17 로 같은 링크 질량·관성·관절로 v2/v5 를 같은 조건에서 비교(발 = 22.5 mm 구, 마찰 0.8, PD Kp 150 / Kd 4 N·m(·s)/rad 가정, 토크는 모터 피크에서 자름).

| 시험 | 항목 | v2 | v5 |
|---|---|---|---|
| 보고서 자세로 서기 | 무릎 유지 토크 / 발 반력 최대 | 8.8 N·m / 75 N | 9.5 N·m / 82 N |
| 5 cm 낙하 | 무릎 / 엉덩이 피치 최대 토크, 발 반력 최대 | 25.2 / 13.6 N·m, 205 N | 26.5 / 14.3 N·m, 218 N |
| 1 Hz 웅크리기 | 무릎 최대 토크 | 13.9 N·m | 15.3 N·m |

모든 시험에서 토크 포화 없음(피크 53 N·m 의 절반 이하), 낙하 착지 발 반력 218 N < 구조 설계 하중 380 N. 보행 제어기가 없어 보행 자체는 시험하지 못함 — 보고서 쪽 ROS2/Isaac 시험(`model_15699`)을 이 USD 로 다시 돌려 확인할 것.
